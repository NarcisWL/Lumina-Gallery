# WebUI 统一浏览器式工具栏实施计划

**目标：** 将地址导航、作用域搜索、排序与布局控制合并为单行固定工具栏，并让媒体库、收藏夹和文件夹成为互不污染的平行位置空间。

**架构：** 继续使用 `GalleryLocation.view` 作为唯一空间判别；标准化层保证非文件夹视图不携带 `folderPath`。统一工具栏中央区域在地址模式与搜索模式间切换，右侧承载排序和布局控制。搜索草稿不进入 History，提交搜索使用 push，排序与布局使用 replace。

## 约束

- 不修改后端 API、数据库或媒体扫描逻辑。
- 不建立与 `GalleryLocation.view` 并行的第二套路由状态。
- 保持现有旧 Hash 深链兼容。
- 保持文件夹返回位置、分页缓存和媒体查看器历史能力。
- 桌面常规宽度保持单行；移动端使用地址摘要、搜索和更多菜单降级。
- 没有筛选、批量操作或状态提示时，不保留常驻第二行。
